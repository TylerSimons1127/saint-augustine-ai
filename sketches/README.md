# Front-End Mockups (Round 2) — Saint Augustine AI

Three **light** liquid-glass directions. Built from scratch after the first round was rejected as vibe-coded and not premium. This round ran the loop: build → render → **harsh vision critique** → fix → re-render. The first pass failed the critique (bright photo destroyed text contrast, gold read as brass, user bubble was loud gold) — those are fixed in the versions below.

## What changed vs round 1 (the fixes)
- **Contrast:** replaced the bright competing photo with a soft gradient field + faint blurred photo — text now reads cleanly on glass.
- **Gold:** desaturated from brass/mustard to antique bronze, used only as accent.
- **User bubble:** dark ink instead of loud gold (anchor, not noise).
- **Hierarchy:** darker ink, deeper bubble shadows, anchored "Augustine" label, real component depth.
