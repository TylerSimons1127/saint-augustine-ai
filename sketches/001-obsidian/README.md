## Variant 1 — Lumina (Liquid Glass Sanctuary)

**Stance:** A calm, light sanctuary. Soft parchment field (not a competing photo), frosted liquid-glass panels float over it, gold is antique bronze used sparingly. Atmosphere toggle (Daylight / Serene) shifts the whole scene.

**Key choices**
- Background: soft warm gradient field + a *faint, blurred* photo presence (opacity .16) so text always wins
- Glass: `backdrop-filter: blur(30px) saturate(180%)` on top bar, composer, bubbles, drawer — true liquid glass with inset highlight + soft drop shadow
- Motion: floating gradient orbs, staggered hero rise, message pop-in, typing dots, focus-glow on composer, drawer slide-in
- User bubble = deep ink (not gold); gold reserved for accents only
- Color: antique bronze `#a3822f`, ink `#211c14`

**Trade-offs**
- Strong at: atmosphere, calm, making glass feel real and premium
- Weak at: not a "tool" — fewer surfaces than 003

**Best for:** the default home screen you'll actually ship — beautiful, serene, on-brand.
