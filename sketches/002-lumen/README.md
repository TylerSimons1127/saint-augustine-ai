## Variant 2 — Lumen (Frosted Glass Daylight)

**Stance:** Bright, airy, minimal. Cooler light field (soft blue-grey gradient), the same liquid-glass system as 001 but lighter and more open. Background switcher (Mountains/Sea/Cathedral/…) in the header.

**Key choices**
- Background: cool parchment-sky gradient + faint blurred photo
- Glass: same blur/saturate recipe, slightly cooler tints
- Motion: floating orbs, hero rise, message pop, typing, composer focus-glow
- User bubble = deep slate ink; gold = antique bronze accents
- Signature: a one-tap background switcher instead of a drawer

**Trade-offs**
- Strong at: brightness, simplicity, "breathable"
- Weak at: least distinctive of the three (closest to a polished generic chat — but glass + bronze lift it)

**Best for:** users who want it light and uncluttered, almost like a bright study window.
