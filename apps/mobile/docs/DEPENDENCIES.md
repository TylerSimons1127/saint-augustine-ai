# Dependency audit — 2026-10-14

The installed Expo SDK57 lockfile reports 30 transitive findings (18 high,12 moderate), arising from four underlying advisories. Zero critical findings. This is not a clean audit claim. Registry versions and runtime/build reachability were inspected; forced downgrades proposed by npm would break the current framework.

| Dependency                | Finding and reachability                                                                                                                                               | Current handling                                                                                                                                                                                                                                          |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| braces3.0.3               | Stack exhaustion from nested glob patterns. Used by Metro/build globbing, not by a user-facing app feature. Latest registry release remains3.0.3.                      | Trusted source/build inputs only. Review upstream patch before release.                                                                                                                                                                                   |
| node-forge1.4.0           | RSA signature validation parsing. Expo CLI/build-signing dependency; app screens do not call this Node library. Latest registry release remains1.4.0.                  | Treat incoming signing assets as trusted Apple/EAS-owned material; review compatible upstream fix before release.                                                                                                                                         |
| uuid7.0.3                 | Bounds checks in v3/v5/v6 with a supplied buffer; xcode project tooling uses this dependency.                                                                          | No app feature supplies UUID buffers. Do not force an incompatible ESM major into CommonJS Xcode tooling.                                                                                                                                                 |
| decode-uri-component0.2.2 | Malformed-percent-input denial of service in Router's query-string dependency. A patched0.5.0 is ESM; blindly overriding the CommonJS dependency can break navigation. | Native `+native-intent` validates standard percent decoding and bounds external link length before Router parses it. Tests cover malformed and oversized input. Internal routes use controlled parameters. Upgrade through a compatible Router/SDK patch. |

Advisories: [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm), [node-forge](https://github.com/advisories/GHSA-86w9-cpqp-85rv), [uuid](https://github.com/advisories/GHSA-w5hq-g745-h8pq), [decode-uri-component](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr).
